### 📌 Featured Project

**[NEU Room Log](https://github.com/ZyCallado/neu-room-log)**

NEU Room Usage Log is a Progressive Web Application (PWA) built for New Era University to simplify and modernize classroom utilization tracking. Professors can quickly check into classrooms by scanning QR codes, while administrators get a real-time view of room activity, usage trends, and institutional data.

The platform combines QR-based room check-ins, automated session management, role-based access control, and AI-powered analytics into one centralized system. Built with Next.js, Firebase, and Google AI, it provides a responsive, mobile-friendly experience designed for both everyday classroom use and administrative management.
